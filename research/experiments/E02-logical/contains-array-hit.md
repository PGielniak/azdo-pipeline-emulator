# oracle probe — contains-array-hit

Expression: `contains(parameters.items, 'BETA')`. Settles whether contains accepts arrays and, if so, comparison casing.

- Endpoint: `POST {org}/{project}/_apis/pipelines/{pipelineId}/preview?api-version=7.1`
- Request body: `{"previewRun": true, "yamlOverride": <below>}`
- Outcome: **HTTP 400 · rejected · typeKey=PipelineValidationException**

### Request — yamlOverride

```yaml
parameters:
- name: items
  type: object
  default: [Alpha, beta, 1]
variables:
  probe: ${{ contains(parameters.items, 'BETA') }}
steps:
- script: echo done
```
