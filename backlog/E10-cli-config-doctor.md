- [x] **E10-S02-T02 — `run` convenience proxy** *(done 2026-08-26: `packages/cli/src/run/run.ts` — `runProject(outdir, args)` spawns `bash run.sh` with `stdio: 'inherit'` and reports the child's status as its own. **The guard the Do field asks for is the first test in the file:** the module's source, with comments stripped, is asserted to contain **none** of `run.sh`'s flag names (`--list`, `--env-file`, `--resume`, `--from-step`, `--to-step`, `--only-step`). A proxy that learned them would be a second place to update whenever the emitter changes, and would diverge silently from the script it fronts. **Exit-code transparency is the contract, not a nicety:** `run.sh` ends with `exit "$(azdo_run_exit_code)"`, so its status *is* the pipeline's verdict, and collapsing it onto the CLI's own 0/1/2 would make `azdo-emu run` and `bash run.sh` disagree about whether the pipeline passed. The status therefore passes through untouched — including 126/127 from the shell and **128+N** for a fatal signal, both pinned to the GNU Bash Reference Manual v5.3 §3.7.5 (C-E13-020/021/022, newly deep-verified). A `ProxiedExit` carries it out through the one exit path, and `run()`'s return type widened from `ExitCode` to `number` for exactly that reason. `os.constants.signals` supplies N rather than a hard-coded table, because `SIGUSR1` is 10 on Linux and 30 on macOS. Commander needed `enablePositionalOptions()` + `passThroughOptions()` so `azdo-emu run out --list` hands `--list` to the script instead of rejecting it here. **Δ recorded, not hidden:** Node has no `exec(3)`, so an intermediate process exists where a shell proxy would have replaced its image — the observable status is identical, but a signal delivered to the proxy is not automatically delivered to the child's group. Done met: **e2e parity** compares proxy vs direct `bash run.sh` on a real converted project — success, a non-zero verdict, `--list`, an unknown flag (`run.sh`'s exit 2, not ours) and a fatal signal — each on both exit code and behaviour. 18 tests; full suite **2188 green**.)*
